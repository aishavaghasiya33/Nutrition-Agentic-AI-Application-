🤖 About NutriCoach AI

🏗️ Agentic AI Architecture

Built following the full Agentic AI SDLC, NutriCoach implements a ReAct (Reason + Act) agent loop:

  1. THINK — Analyse user profile
  2. ACT — Call registered tools
  3. REASON — Build enriched context
  4. GENERATE — IBM Granite LLM inference
  5. VALIDATE — Guardrail safety checks
  6. OUTPUT — Safe, personalised plan

🔧 Agent Tools

  • get_local_foods — Regional food database
  • get_medical_adjustments — Condition-specific diet rules
  • calculate_bmr — Mifflin-St Jeor calorie estimation
  • answer_query — Multi-turn Q&A with context

🛡️ Ethics & Guardrails

  • HAM principles (Helpful, Accurate, Mindful)
  • Input safety & prompt injection detection
  • Output scanning for harmful advice
  • Condition-specific medical warnings
  • Mandatory medical disclaimer
  • No PII stored server-side

🤖 IBM Granite Model

Uses ibm/granite-13b-instruct-v2 via IBM watsonx.ai platform. The model is configured with safety constraints, repetition penalties, and domain-specific system prompts to ensure nutritionally accurate and ethically responsible output.

When credentials are not configured, the app runs in offline mode with a structured rule-based plan generator, ensuring the app is always demonstrable.
